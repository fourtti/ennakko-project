## Tiedot

Yksinkertainen "SPA" (single page application) yksinkertaisella käyttöliittymällä, jolla voi hakea PRH datasta yrityksen nimellä tai y-tunnuksella.


## Käyttö

1. Avaa `index.html` selaimessa (tuplaklikkaa tiedostoa).
2. Kirjoita yrityksen nimi "Yrityksen nimi" -kenttään tai y-tunnus
   (esim. `0112038-9`) "Y-tunnus" -kenttään. Voit käyttää kumpaa tahansa.
3. Paina "Hae".
4. Löytyneet yritykset ilmestyvät taulukkoon.
